# Локальні медіафайли (лише для розробки)

Покладіть сюди відео (`.mp4`), постери та субтитри (`.vtt`), які ви передали для набору.
Під час `npm run dev` / `npm run preview` вони доступні за адресою `<base>media/<шлях>`
і підключаються через поле `localPath` у карті відео (`video-map.json`).

Ця папка не потрапляє в Git (крім цього файлу) і не публікується разом із сайтом.
Для опублікованого сайту завантажте відео у вибране сховище/CDN і вкажіть `publicUrl`.
